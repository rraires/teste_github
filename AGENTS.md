# Instruções para o agente

Este repositório existe apenas para aprender e praticar Git.

- Responda em português do Brasil, de forma simples e objetiva.
- Ao realizar uma operação Git, explique brevemente o que ela faz.
- Faça apenas as alterações necessárias para atender ao pedido.
- Mantenha os arquivos de texto em UTF-8.
- Não adicione ferramentas ou dependências sem necessidade para o exercício.
